# マッチョを目指そうRPG

雑居ビル3階のプライベートサロンで、高瀬航（たかせ わたる、「高瀬さん」）に見てもらいながらマッチョを目指す、軽いブラウザRPGです。実際にやったスクワットや腕立ての回数が、経験値になります。

公開URLは [https://ayumisan.github.io/slot-091/](https://ayumisan.github.io/slot-091/) です。ページの出どころは `main` ブランチのルートです。

## 遊び方

1. ページを開く。呼び名は最初「由衣さん」です。その欄で変えられます。
2. 「はじめる」か、続きがあるときは「つづきから」。
3. 高瀬さんの挨拶を「次へ」で送る。
4. 「トレーニングする」で種目を選ぶ。
   - **数えながら**: `+1` で実際の回数（プランクは秒）を数える。プランクは「秒を計測」でも数えられます。
   - **まとめて記録**: 終わった回数とセット数をまとめて入れる。
5. 「セットを記録」で経験値が入る。筋力、体力、メンタルがレベルアップし、体の段階が「これから」から「高瀬さん公認マッチョ」へ進みます。
6. 予定より早くやめたときは「今日はここまで」。やった分だけ経験値になり、高瀬さんは「今日やっただけで偉い」と褒めます。0回でも責めません。
7. 痛みが出たら「痛み」。そこまでの分は残り、続けることは勧めません。
8. 「依頼」は日付で3件（最初だけ、スクワット10回の案内つき）。達成すると報酬の経験値が入ります。
9. トレーニングした日が続くと、3日・7日・30日でごほうびがあります。空いても、戻った日を褒めます。
10. 「ボス」は、セットを終えると残りが減る相手です。途中でやめても、減った分は残ります。前の相手をクリアすると次が出ます。
11. ホームの「今日はここまで」で店じまいです。
12. 「記録」で呼び名の変更、14日の印、履歴、全身の高瀬さんを見られます。記録を消すこともできます。

このゲームは医療の助言ではありません。痛みや違和感が出たら、その場でやめてください。

## セーブ

このブラウザの `localStorage` にだけ残ります。キーは `machoRpg.v1` です。サーバーにも、リポジトリにも、APIキーも送りません。合鍵は入っていません。

## 手元で開く

モジュールを使っているので、フォルダを直接開くと動きません。

```bash
python3 -m http.server 8000
```

ブラウザで http://127.0.0.1:8000/ を開いてください。

ロジックの確認は次です。

```bash
node --test
```

## 高瀬さん

表情は約300ミリ秒でクロスフェードします。同じ顔を短時間に何度も切り替えないよう、次の表情までは少し間を置きます。褒め言葉は場面ごとに引き出しを分けて、直前と同じセリフを避けます。

立ち絵と表情、サロンの背景は [ayumisan/slot-097](https://github.com/ayumisan/slot-097) の画像です。口調と「具体的に、くり返さず、途中でやめても褒める」は、公開されている筋トレ応援の高瀬さんに合わせています。

設定は、公開されている高瀬航のサロンです。雑居ビルの3階、入会金も月額もなく都度払い、チャコールのポロ、右頬の浅いえくぼ。プレイヤーの初期の呼び名は由衣さんです。非公開の slot-096 は変更しておらず、原文や秘密情報もコピーしていません。この環境からはそのリポジトリを読めなかったため、物語は公開側の設定だけを使っています。
